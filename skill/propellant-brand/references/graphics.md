# Graphic devices and print color

## Graphic devices

These are the standard graphic devices. Build them from the palette and the logo files; never
redraw the logo.

| Device                | What it is                                                                                                                  | Use it for                               |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| Geometric pattern     | Bright teal and Pale teal triangles with an Oswald label in capitals on top, such as ACCELERATOR. The brand pattern.        | Covers and headers                       |
| Teal duotone          | A photo washed from Deep teal to Bright teal                                                                                | Backgrounds behind text, section headers |
| Hexagon network frame | A circular photo crop inside a pale teal network of hexagons and lines                                                      | One photo beside text                    |
| Co-brand lockup       | MassChallenge logo, a plus sign and the partner logo, on white with a thin teal border, or a teal panel with the white logo | Work made with a partner                 |
| Program lockup        | The MC monogram, a thin vertical divider and the program name in capitals, such as MC \| RESOLVE 2026                       | A named program or event                 |
| Stat callouts         | A large number with a short label in capitals                                                                               | One figure that matters                  |
| Program timelines     | Dots on a line, with each step above or below its dot                                                                       | Program and application dates            |
| Icons                 | Single color line icons with rounded ends, Teal on light, Bright teal on dark                                               | Labels for areas and steps               |

- Text on the pattern must pass contrast against both colors. Set the label in Ink, or in White on a
  solid Deep teal panel. Never White straight on the triangles: White on Bright teal is about 2.7:1,
  below 3:1 even for large text.
- Stat numbers are Deep teal on light backgrounds and Bright teal on dark ones, with the label in
  Ink or White. Never Magenta: it only ever means something is wrong.
- Timeline dots follow the chart order: Teal, Yellow, Slate, Bright teal, Deep teal, Gray 300. The
  words beside each dot carry the meaning.
- Icons are always paired with a word.

## Print color

| ----------- | --------- | ------------ |
| Deep teal   | `#044451` | 100 64 53 50 |
| Teal        | `#065E6F` | 100 55 45 24 |
| Mid teal    | `#068DA4` | 87 31 31 2   |
| Bright teal | `#0FACBD` | 78 11 26 0   |
| Pale teal   | `#D9F6FA` | 13 0 2 0     |
| Mist        | `#F3FBFC` | 3 0 1 0      |
| Magenta     | `#BF0261` | 21 100 42 5  |
| Yellow      | `#FFC801` | 0 22 100 0   |
| Ink         | `#1E282B` | 81 66 63 83  |
| Slate       | `#4B575B` | 73 57 55 35  |
| White       | `#FFFFFF` | 0 0 0 0      |
| Gray 100    | `#DBE1E3` | 13 7 8 0     |
| Gray 300    | `#848F92` | 53 38 39 4   |
| Logo gray   | `#828486` | 53 44 43 7   |
| Logo teal   | `#17ACBC` | 77 11 27 0   |

CMYK values are calculated from the sRGB values with the Artifex CMYK SWOP profile (US web coated),
relative colorimetric intent, rounded to whole percent. Check a printed proof before a large run.
Logo gray and Logo teal belong to the logo artwork only.
