# Graphic devices and print color

## Graphic devices

These are the graphics masschallenge.org uses today, and they are the standard. Build them from the
palette and the logo files; never redraw the logo.

| Device                | What it is                                                                                                                  | Use it for                               |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| Geometric pattern     | Bright teal and Pale teal triangles with an Oswald label in capitals on top, such as ACCELERATOR. The brand pattern.        | Covers and headers                       |
| Teal duotone          | A photo washed from Deep teal to Bright teal                                                                                | Backgrounds behind text, section headers |
| Hexagon network frame | A circular photo crop inside a pale teal network of hexagons and lines                                                      | One photo beside text                    |
| Co-brand lockup       | MassChallenge logo, a plus sign and the partner logo, on white with a thin teal border, or a teal panel with the white logo | Work made with a partner                 |
| Program lockup        | The MC monogram, a thin vertical divider and the program name in capitals, such as MC \| RESOLVE 2026                       | A named program or event                 |
| Stat callouts         | A large number with a short label in capitals                                                                               | One figure, with its as of date          |
| Program timelines     | Dots on a line, dates above and below                                                                                       | Program and application dates            |
| Icons                 | Single color line icons (Noun Project), Teal on light, Bright teal on dark                                                  | Labels for areas and steps               |

- Text on the pattern must pass contrast against both colors. White on Bright teal is about 2.7:1,
  below 3:1 even for large text, so set the label in Ink or put it on a solid Deep teal panel.
- Stat numbers are Deep teal on light backgrounds and Bright teal on dark ones. Never Magenta: it
  only ever means something is wrong.
- The Noun Project licence MassChallenge holds is not known. Say it needs confirming before adding
  new icons.

### Off palette colors on the website

Map these to the palette when you rebuild a piece:

- Icon tints `#00708E`, `#00BBC3`, `#5CE1E6`, `#0EABBC`: Teal or Bright teal.
- Crimson stat numbers: Deep teal on light, Bright teal on dark.
- Orange, purple and green timeline dots: the chart order (Teal, Yellow, Slate, Bright teal, Deep
  teal, Gray 300).

| ----------- | --------- | ------------ |
| Deep teal   | `#044451` | 100 64 53 50 |

| Slate       | `#4B575B` | 73 57 55 35  |
| White       | `#FFFFFF` | 0 0 0 0      |
| Gray 100    | `#DBE1E3` | 13 7 8 0     |
| Gray 300    | `#848F92` | 53 38 39 4   |
| Logo gray   | `#828486` | 53 44 43 7   |
| Logo teal   | `#17ACBC` | 77 11 27 0   |

CMYK values are calculated from the sRGB values with the Artifex CMYK SWOP profile (US web coated),
relative colorimetric intent, rounded to whole percent. Check a printed proof before a large run.
Pantone matches are not set; print from the CMYK values. Logo gray and Logo teal belong to the logo
artwork only.
