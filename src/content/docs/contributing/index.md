---
title: Contributing
description: How changes to Propellant are proposed, designed and reviewed.
---

The MassChallenge team owns and maintains Propellant and decides what goes into each release.

## Design comes first

Any new component or visual change starts as an approved design, made in a design tool such as
Figma or Claude Design, before any code is written. The pull request is desk checked against that
design, and the review by the MassChallenge design lead is the final check before it is merged.

## Where a change goes

- **A change to one platform**, such as a web component, goes to that platform's repository. The
  [web repository](https://github.com/masschallenge/propellant-web) has its own
  [contributing guide](https://github.com/masschallenge/propellant-web/blob/main/CONTRIBUTING.md).
- **A change to this site**, such as a shared page or the navigation, goes to
  [`masschallenge/propellant`](https://github.com/masschallenge/propellant).
- **Brand changes** to the logo, colors, fonts or voice come from the MassChallenge brand team.

## Security problems

Never report a security problem in a public issue. Use the **Report a vulnerability** button on the
repository's **Security** tab instead, so only the maintainers can see it.
